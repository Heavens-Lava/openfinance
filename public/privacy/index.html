Privacy

Your financial data stays under your control.

OpenFinance is designed to analyze bank CSV exports locally in your browser without connecting to your bank or sending the contents of those files to an OpenFinance server.

What happens to imported files

The public OpenFinance application reads and parses selected CSV files on your device. It stores imported file contents in this browser's IndexedDB so you can restore them later. Category changes, rules, goals, and interface preferences may be stored in browser local storage.

What OpenFinance does not collect

  • Bank usernames or passwords
  • Bank API credentials or connection tokens
  • The contents of imported CSV files on an OpenFinance server
  • Advertising profiles created from financial activity

Network requests

The application itself is delivered over the internet and currently loads its interface files and fonts from hosting providers. These requests can expose ordinary connection information such as an IP address to those providers. Imported financial data is not included in those requests.

Deleting local data

Use Clear data inside OpenFinance to remove saved imports from the application's browser storage. Browser site-data controls can also remove IndexedDB, local storage, and cached application files for finance.jeffreymacy.com. Deleting local browser data cannot be undone.

Desktop application

The Windows application uses the same local-first interface. Files remain on the device unless you independently copy, back up, or share them.

Scope and changes

This policy describes the public OpenFinance deployment at finance.jeffreymacy.com. Separately configured forks or private deployments may behave differently. Material changes will be recorded in the project repository.

Effective: August 3, 2026. Questions or responsible reports may be submitted through GitHub Issues; security reports should follow the security page.
